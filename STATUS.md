# Artifact Status

This artifact is prepared as a public replication package for:

**Diff-Grounded Pull Request Description Generation with Structured Evidence**

The package is intended to support inspection, rerunning, and extension of the
paper's diff-grounded pull-request description generation workflow.

## Badge Intent

This repository is structured for an **Available** artifact release and for
review under **Reusable**-style expectations:

- documented repository layout
- installation and execution instructions
- runnable source code and configuration
- included input datasets
- included human-study inputs
- scripts for regenerating evaluation summaries
- canonical paper figures

## Included

- Pipeline source code for GitHub artifact collection, PRContext construction,
  PR-description generation, and LLM-based judging.
- Input dataset CSV files under `data/`.
- Human-study inputs under `final-results/data/human-data/`.
- Analysis scripts under `final-results/scripts/`.
- Canonical camera-ready figure PDFs under `figures/`.
- Documentation for architecture, setup, execution, and expected outputs.

## Not Included

The following files are generated by running the pipeline and are intentionally
not versioned in the source repository:

- `results/`
- `final-results/eval/`
- `final-results/data/description-data/`
- local secrets such as `.env`
- local virtual environments

These exclusions are recorded in `.gitignore` and described in the README.

## Reuse Notes

The artifact can be used to rerun the pipeline on the provided PR target lists
or on new GitHub pull requests by changing the dataset/configuration and
providing the required GitHub and LLM credentials.
